# Release notes

## v1.0.0 -- 2026-10-22

Initial public release of the Paper A reproducibility package.

- Analysis scripts covering date decoding, case-history construction, the
  pairwise and three-event random-effects models, state-dependence checks,
  forecast designs and figure generation.
- Aggregate outputs from the verified full rerun (2026-10-18).
- Figure exports (PDF, PNG, SVG) for the six manuscript figures.
- Data-source links and the public boundary.
