# Public boundary

This release contains aggregate outputs only. Site-level maps, the complete
site-term tables, raw CPT profiles, NZGD identifiers and source archives remain
outside the public repository. The local submission package and the analysis
trees are not part of this release.

Raw inputs must be obtained from the original providers under their own terms:

- DesignSafe PRJ-2937 (DOI 10.17603/DS2-TYGH-HT91) for the Canterbury CPT
  case histories;
- the New Zealand Geotechnical Database for repeat soundings and investigation
  metadata;
- GNS Science Geological Map 3 for the geomorphological context.
